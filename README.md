## Controls

**Left click** to Place blocks

**Right Click** to Break Blocks

**Q** and **E** to cycle between blocks

hold **TAB** to hide ui

hold **WASD** to move

hold **LEFT SHIFT** to run

experiments:

    press **t** to test damage, deals 5 hp of damage.
